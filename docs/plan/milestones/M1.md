# M1 Ledger kernel: accounts, categories, adjustments, balances, settings, periods

Scope and work breakdown: `IMPLEMENTATION_PLAN.md` section 4, M1. Requirements: RF-01, RF-05,
RF-06, ADR-003, ADR-007, ADR-008, ADR-010, ADR-012, ADR-013, TRD-5.2. QA evidence:
`QA_LOG.md`, section "M1 Ledger kernel".

## Acceptance criteria

- [x] **1. Account lifecycle.** All four account types can be created, edited, archived and
  unarchived; an account with movements returns 409 `account_has_movements` on delete but can be
  archived; archived accounts are hidden from pickers and listed with `include_archived=1`.
  Evidence: `backend/tests/Feature/Actions/AccountActionsTest.php`,
  `backend/tests/Feature/Api/AccountsApiTest.php`, Playwright `m1-ledger.spec.ts`
  ("create the four account types...", "archive and unarchive an account").
- [x] **2. Balances and adjustments.** Balance equals opening balance plus live movements up to
  today; an adjustment to a target balance yields exactly that balance at its date; a zero-delta
  adjustment returns 422.
  Evidence: `backend/tests/Feature/Domain/BalanceCalculatorTest.php`,
  `backend/tests/Feature/Actions/RecordBalanceAdjustmentTest.php`,
  `backend/tests/Feature/Api/AccountsApiTest.php`, Playwright "adjust a balance to a target and
  see the computed delta".
- [x] **3. DB-enforced invariants.** Raw SQL inserts violating every rule in `DATA_MODEL.md`
  (sign, category kind, depth, opening date, archived account, unbalanced transfer legs, card
  settlement accounts) are rejected by PostgreSQL.
  Evidence: `backend/tests/Database/*ConstraintsTest.php`,
  `backend/tests/Database/EnumCheckConsistencyTest.php`, `backend/tests/Database/MigrationsTest.php`.
- [x] **4. Configurable periods.** With `month_start_day=25`, `GET /periods/current` on
  2026-10-13 returns label `2026-10`, start `2026-09-25`, end `2026-10-24`; with 1 it returns the
  calendar month.
  Evidence: `backend/tests/Unit/Domain/PeriodResolverTest.php`,
  `backend/tests/Feature/Api/SettingsAndPeriodsApiTest.php` ("returns the payday period on
  2026-10-13 with start day 25", "returns the calendar month with start day 1"), Playwright
  "change the month start day and see the period preview".
- [x] **5. Categories.** Categories and subcategories are editable per kind and a child can never
  get the other kind.
  Evidence: `backend/tests/Feature/Actions/CategoryActionsTest.php`,
  `backend/tests/Feature/Api/CategoriesApiTest.php`,
  `backend/tests/Database/CategoriesConstraintsTest.php`.
- [x] **6. Ledger verification.** `app:ledger:verify` passes on the dev seed and fails on
  deliberately corrupted data.
  Evidence: `backend/tests/Feature/Console/VerifyLedgerCommandTest.php`; runtime image run on the
  dev seed printed `Ledger OK` (see `QA_LOG.md`).
- [x] **7. QA gate.** Green, including the M0 and M1 Playwright journeys: 17/17 passed
  (setup + `m0-auth` + `m1-ledger` on Chromium and WebKit) against the production compose stack.
